# Fahrzeugverwaltung

Mobile PWA zur Verwaltung von Autos und Motorrädern.

## Funktionen
- Fahrzeugtyp: Auto oder Motorrad
- KBA-Nummer (HSN / TSN)
- Kennzeichen, Marke/Modell, Baujahr, FIN/VIN
- Kilometerstände und Historie
- Service und Reparaturen mit Kosten
- TÜV und Erinnerungen
- Fotos per Kamera/Galerie
- Dokumente
- JSON-Sicherung und Import
- Offline-Nutzung nach dem ersten Laden

## GitHub Pages
Repository auf GitHub hochladen und unter **Settings → Pages** den Branch `main` und `/ (root)` aktivieren.

Danach die erzeugte Pages-Adresse auf Android/Chrome öffnen und über **⋮ → App installieren** zum Startbildschirm hinzufügen.
